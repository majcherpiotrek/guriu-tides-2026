# Guriú tide calendar – 8 Oct to 30 Nov 2026

Static tide calendar for windsurfing in Guriú / Jericoacoara (Ceará, Brazil).

- `index.html` – the calendar (served by GitHub Pages)
- `tides.csv` – the same data as a table
- `tides.py` – generator; edit the `RAW` block and run `python3 tides.py` to rebuild both files (needs `pip install astral`)

Predictions come from temperaturadomar.pt for Jijoca de Jericoacoara and are not official DHN tables.

## Deploy

Repo Settings → Pages → Source "Deploy from a branch" → branch `main`, folder `/ (root)`.
